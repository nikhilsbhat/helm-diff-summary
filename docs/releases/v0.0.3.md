# helm-diff-summary v0.0.3

Use helm-diff-summary as either a standalone utility or an optional Helm plugin.

## Helm Plugin

The `diff-summary` plugin supports Helm 3 and Helm 4. It runs the same binary, accepts the same flags and piped input, and preserves policy exit codes.

Helm 3:

```bash
helm plugin install https://github.com/nikhilsbhat/helm-diff-summary --version v0.0.3
```

Helm 4:

```bash
helm plugin install https://github.com/nikhilsbhat/helm-diff-summary --version v0.0.3 --verify=false
```

Both versions:

```bash
helm diff upgrade app ./chart --allow-unreleased --output diff | helm diff-summary
```

The plugin install/update hook downloads the matching release binary and verifies its SHA-256 checksum. It supports Linux, macOS, and FreeBSD. Helm 4's `--verify=false` skips Helm plugin provenance verification for the Git source; the hook still verifies the binary archive checksum.

Standalone binaries, JSON/YAML output, policy configuration, and notifications retain their existing interfaces. Install helm-diff separately to generate the diff input.

## Other Changes

- Add Go tests and a CI coverage gate requiring at least 90% total statement coverage.
- Add plugin integration tests and a Helm 3/4 CI matrix.
- Improve installation, CI examples, and contributor documentation.

Releases before v0.0.3 do not contain the plugin manifest and cannot be installed as this Helm plugin.
